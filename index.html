1. 📊 Dashboard
El Dashboard es la pantalla de inicio. Muestra el estado general del sistema.

¿Qué muestra?
• Subgrupos registrados: cuántos subgrupos de datos hay cargados.
• Producto activo: el producto y variable seleccionados en Trazabilidad.
• Estado del proceso: indica si hay datos cargados.
• Resumen de Trazabilidad: muestra los metadatos del estudio actual.
• Guía Rápida: pasos recomendados para usar la aplicación de inicio a fin.

¿Cómo usarlo?
No se requiere ninguna acción aquí. Es un panel informativo. Comienza siempre por la sección Trazabilidad.

3. 📥 Ingreso de Datos
Hay dos métodos para ingresar datos: texto manual y carga de Excel/CSV.

Método 1 — Texto / Manual:

  1. Selecciona Tipo de datos: Variables (continuas) o Atributos (discretos).
  2. En el área de texto, escribe o pega los datos.
    • Para variables: cada fila es un subgrupo, valores separados por coma o espacio.
       Ejemplo: 12.3, 11.8, 12.1, 11.9, 12.4 (subgrupo 1)
    • Para atributos: una sola fila con los conteos separados por coma.
       Ejemplo: 3, 5, 2, 7, 4, 1, 6, 3
  3. Haz clic en 📤 Cargar Datos.
  4. Verifica la tabla generada abajo. Mostrará X̄ y R por subgrupo.
  5. Usa 🎲 Generar Ejemplo si quieres probar con datos simulados.

Método 2 — Excel / CSV:

  1. Prepara tu archivo Excel (.xlsx / .xls) o CSV con los datos organizados:
    • Variables: fila 1 = encabezados (X1, X2…), filas siguientes = subgrupos.
    • Atributos: una columna con los valores por subgrupo.
  2. Ve a la pestaña 📊 Desde Excel / CSV.
  3. Arrastra el archivo al área indicada o haz clic en Seleccionar archivo.
  4. Configura si el archivo tiene encabezados y el tipo de datos.
  5. Revisa la Vista Previa para confirmar que los datos se leyeron bien.
  6. Haz clic en ✅ Confirmar y Cargar Datos.
4. 📉 Gráfico X̄ – R
Controla la media y la dispersión (rango) del proceso. Ideal para n ≤ 10.

Pasos:
1. Asegúrate de tener datos cargados (variables continuas, mínimo 25 subgrupos).
2. Ingresa el LSE (Límite Superior de Especificación) y LIE (Límite Inferior), si los conoces.
3. Ingresa el Objetivo (valor nominal deseado), opcional.
4. Haz clic en ▶ Calcular y Graficar.

Cómo interpretar:
• Los puntos rojos = fuera de los límites de control (causas especiales).
• LSC / LIC = Límites de Control (estadísticos, ≠ especificaciones).
• Prueba 1: 1 punto fuera de ±3σ → causa especial inmediata.
• Prueba 2: 9 puntos consecutivos del mismo lado de la línea central → posible desplazamiento.
• Prueba 3: 6 puntos consecutivos en tendencia → proceso moviéndose.
• Si ambos gráficos (X̄ y R) están bajo control → proceso estable.

Fórmulas clave:
  LSC(X̄) = X̄̄ + A₂ · R̄  |  LIC(X̄) = X̄̄ − A₂ · R̄
  LSC(R) = D₄ · R̄  |  LIC(R) = D₃ · R̄

5. 📈 Gráfico X̄ – S
Controla la media y la desviación estándar (S). Más preciso para n > 10.

Cuándo usar X̄–S vs X̄–R:
• Usa X̄–R cuando n ≤ 10 (más simple de calcular manualmente).
• Usa X̄–S cuando n > 10 (S es más precisa que R para muestras grandes).

Pasos: igual que X̄–R. Ingresa LSE, LIE, objetivo y haz clic en ▶ Calcular.

Fórmulas:
  LSC(X̄) = X̄̄ + A₃ · S̄  |  LSC(S) = B₄ · S̄
  LIC(X̄) = X̄̄ − A₃ · S̄  |  LIC(S) = B₃ · S̄

6. 🔔 Prueba de Normalidad
Verifica si los datos siguen una distribución normal. Requisito para Cp, Cpk, Pp, Ppk.

Pasos:
1. Carga tus datos de variables continuas.
2. Haz clic en ▶ Analizar Normalidad.

Resultados que obtendrás:
• Estadístico W (Shapiro-Wilk): cercano a 1 = más normal. Rango [0, 1].
• Valor-p: si p ≥ 0.05 → datos normales (no rechazar H₀).
               si p < 0.05 → datos NO normales (rechazar H₀).
• Histograma: barras de frecuencia + curva normal teórica superpuesta.
• Gráfico Q-Q: si los puntos siguen la línea azul → normalidad confirmada.
• Estadísticas descriptivas: media, desviación, mediana, asimetría, curtosis.

Interpretación de asimetría:
   = 0 → Simétrica | > 0 → Cola hacia la derecha | < 0 → Cola hacia la izquierda

7. ⚙️ Capacidad del Proceso
⚠️ Verifica primero que el proceso esté bajo control (gráficos X̄–R o X̄–S) y que los datos sean normales.

Pasos:
1. Ingresa LSE y LIE (especificaciones del cliente/proceso). Obligatorios.
2. Ingresa el Objetivo (valor nominal). Opcional.
3. Haz clic en ▶ Calcular Capacidad.

Índices y su significado:

8. 🔢 Gráficos P / NP
Para datos de atributos que siguen distribución Binomial (pasa/no pasa).

Gráfico P — Fracción defectuosa:

Usa cuando el tamaño de subgrupo puede variar.
• Ingresa los defectuosos por subgrupo (ej: 3, 5, 2, 7…).
• Ingresa el tamaño n: uno solo si es constante, o uno por subgrupo.
• Haz clic en ▶ Calcular Gráfico P.

Fórmulas:
p̄ = Σd / Σn  |  LSC = p̄ + 3√(p̄q̄/n̄)  |  LIC = p̄ − 3√(p̄q̄/n̄)

Gráfico NP — Número de defectuosos:

Usa cuando el tamaño de subgrupo es constante (variación ≤ 25%).
• Ingresa los defectuosos y el n constante.
• Haz clic en ▶ Calcular Gráfico NP.

Fórmulas:
n̄p̄ = media | LSC = n̄p̄ + 3√(n̄p̄(1−p̄)) | LIC = n̄p̄ − 3√(n̄p̄(1−p̄))

9. 🔣 Gráficos C / U
Para conteo de defectos (no defectuosos). Siguen distribución de Poisson.

Gráfico C — Total de defectos:

Área de oportunidad constante.
Ej: número de manchas en una bandeja de 50 frutas.
• Ingresa el conteo de defectos por subgrupo.
• Fórmulas: c̄ = media | LSC = c̄ + 3√c̄ | LIC = c̄ − 3√c̄

Gráfico U — Defectos por unidad:

Área de oportunidad variable.
Ej: defectos por hoja inspeccionada cuando n varía.
• Ingresa defectos y unidades inspeccionadas por subgrupo.
• Fórmulas: ū = Σc/Σn | LSC = ū + 3√(ū/n̄) | LIC = ū − 3√(ū/n̄)

¿C o U? ¿P o NP?
C y U → cuentan defectos (una pieza puede tener múltiples defectos).
P y NP → cuentan piezas defectuosas (la pieza es buena o mala en total).
10. 📊 Diagrama de Pareto
Identifica los defectos más frecuentes usando el principio 80/20.

Pasos:
1. Haz clic en 🎲 Ejemplo para ver un ejemplo precargado, o borra y escribe tus datos.
2. Por cada tipo de defecto, escribe el nombre y su frecuencia (número de ocurrencias).
3. Usa ➕ Agregar Defecto para añadir más filas.
4. Haz clic en ▶ Generar Pareto.

Cómo leer el diagrama:
• Las barras rosas = frecuencia de cada defecto (orden descendente).
• La línea azul = porcentaje acumulado.
• Los defectos marcados como 80% causas son los más críticos.
• Los marcados como 20% residual son secundarios.
• Decisión: ataca primero los defectos que llegan al 80% acumulado.

11. ⬇ Exportar Excel

El botón ⬇ Exportar Excel en la barra superior genera un archivo CSV descargable con la información de trazabilidad y los datos por subgrupo (incluyendo X̄, R y S calculados).

El archivo se llama AgroStat_CEP_Datos.csv y puede abrirse directamente en Microsoft Excel, Google Sheets o LibreOffice Calc.

Tip: Al abrir en Excel, selecciona el separador coma (,) si el sistema lo solicita.
